# Estudos Front-end: HTML, CSS, JavaScript e React

Este repositório tem como objetivo armazenar, organizar e versionar meus estudos, anotações e projetos desenvolvidos ao longo do curso de Formatação Front-end ministrado pela Udemy.

## Sobre o Repositório

Aqui documento minha trilha de aprendizado e evolução no desenvolvimento web. O repositório está dividido em módulos que acompanham a progressão do curso, começando com a estruturação de páginas, passando pela estilização e, futuramente, abordando a interatividade e a criação de interfaces complexas.

## Tecnologias Utilizadas

Até o momento, as tecnologias aplicadas no repositório incluem:

*   **HTML5** (Estruturação e semântica)
*   **CSS3** (Estilização e layout)
*  **JavaScript**
*  **React**
